# Приложения «Касса и склад»

Тонкие обёртки над веб-кассой `https://ablazov.duckdns.org/kassa/`:

- `android/` — Kotlin, WebView. Открыть папку в Android Studio, собрать APK/AAB.
- `ios/` — Swift, WKWebView. Открыть `KassaSklad.xcodeproj` в Xcode на Mac, собрать IPA через Product → Archive.

Что умеют обёртки, как поменять адрес сервера, как собрать и опубликовать — в [`docs/kassa-mobile.md`](../docs/kassa-mobile.md).
