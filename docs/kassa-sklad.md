# Касса и склад (мобильное веб-приложение)

Отдельное приложение для магазина аксессуаров для телефонов. Оно лежит в `public/kassa/` и не зависит
от Laravel-части проекта: это статические файлы без сборки, данные хранятся в `localStorage` устройства.

- Адрес после деплоя: `https://<домен>/kassa/index.html`
- Локально: `cd public/kassa && python3 -m http.server 8080`, затем открыть `http://localhost:8080/index.html`
- На телефоне можно «Добавить на главный экран» — есть манифест и офлайн-режим (service worker).
  Камера и установка как приложения работают только по HTTPS (или на `localhost`).

## Экраны

| Экран | Что делает |
|-------|------------|
| Главная | Выручка, чеки и проданные единицы за сегодня, предупреждение о низком остатке, последние продажи, 9 быстрых кнопок |
| Продажа | Поиск/скан штрих-кода, популярные товары, корзина, имя покупателя, оплата (наличные / карта / QR), сдача, «Пробить чек» |
| Товары | Поиск, категории, сортировка по названию, цене и остатку, фильтр «Мало на складе», карточка с EAN-13 и движением товара, «Добавить товар» |
| Приход | Документ прихода от поставщика: товары, количество, закупочная цена |
| Возврат | Возврат по номеру чека: товар возвращается на склад, сумма вычитается из выручки |
| Инвентаризация | Ввод фактических остатков (скан = +1), недостача и излишек, проведение выравнивает остатки |
| Отчёты | Сегодня / неделя / месяц / всё время: выручка, чеки, единицы, средний чек, прибыль, график, оплаты, продавцы, топ товаров, низкий остаток, стоимость склада |
| Журнал | Все операции по дням с поиском и фильтром по типу |
| Сотрудники | Владелец и продавцы, кто сейчас на кассе, статистика по каждому |
| Сканер | Камера (BarcodeDetector, иначе ZXing с jsDelivr), фото штрих-кода или ввод цифр; USB/Bluetooth-сканеры работают как клавиатура |

## Правила учёта

- Остаток товара меняют только операции: продажа (−), возврат (+), приход (+), инвентаризация (= факт).
  Начальный остаток нового товара записывается приходом «Начальный остаток».
- Выручка = сумма продаж − сумма возвратов (по дате возврата). Средний чек = продажи / число чеков.
  Валовая прибыль = выручка − себестоимость (закупочная цена на момент продажи).
- Продать больше остатка нельзя; вернуть больше, чем куплено по чеку, нельзя.
- Каждая операция записывается на сотрудника, который сейчас на кассе (переключатель в шапке).
- Приход обновляет закупочную цену товара на последнюю.
- Новый штрих-код проверяется как EAN-13 (контрольная цифра, уникальность). Пустое поле — приложение
  создаёт внутренний код с префиксом `200`. 12-значный UPC-A дополняется ведущим нулём.

## Данные

- Ключ хранилища: `kassa-sklad:v1`. При первом запуске загружается демо-магазин: 48 товаров в 6 категориях,
  4 сотрудника, продажи за 30 дней (8 из них — сегодня), приходы, возвраты и одна инвентаризация.
  Даты строятся относительно текущего момента.
- «Ещё → Данные»: «Загрузить демо заново» или «Начать с чистого листа» (сотрудники и название магазина остаются).
- Данные живут только в этом браузере на этом устройстве. Очистка данных сайта удаляет учёт.
